# Курс по Claude Code для бизнес-задач

Практический курс по применению Claude Code в задачах, не связанных с разработкой.

## Подготовка окружения

Перед уроками установите клиент (Claude Code или OpenCode) и MCP-серверы, которые используются в практиках (Playwright, Kaiten, векторный поиск). Пошаговая инструкция -- в [demo/setup.md](demo/setup.md).

## Уроки

- [Урок 1](demo/lesson1/) — введение, тренды AI, сложность задач, промпты
- [Урок 2](demo/lesson2/) — команды, работа с документацией, пользовательские агенты
- [Урок 3](demo/lesson2/) — продолжение практического занятия урока 2 «Работа с документацией», базовые промпты
- [Урок 4](demo/lesson4/) — дизайнер и код: стилизация компонентов через ИИ
- [Урок 5](demo/lesson5/) — практика: стилизация компонентов через ИИ и др.
- [Урок 6](demo/lesson6/) — практика: прототипирование
- [Урок 7](demo/lesson7/) — практика: GitLab через OpenCode
- [Урок 8](demo/lesson8/) — практика: правила линтера + управление задачами через Kaiten MCP
- [Урок 9](demo/lesson9/) — ресерч с AI: демо + дискуссия (для продактов)
- [Урок 10](demo/lesson10/) — воркшоп: теория с live-ресерчем (30 мин) + практика (1 ч); требуется OpenCode/Claude Code с MCP (playwright, Kaiten) и glab
- [Урок 11](demo/lesson11/) — разбор необходимых MCP-серверов
- [Урок 12](demo/lesson12/) — AI для маркетинга: экспертиза в рынке и в продуктах

Новые уроки добавляются по мере проведения курса.
