# Демо

## Проблема: экспертиза как бутылочное горлышко

Проблема не только маркетинга -- она общая для сейлзов, дизайнеров, техписов.

**В рынке** хорошо разбирается security-аналитик. **В продуктах** -- архитектор продукта. Все остальные разбираются поверхностно.

При этом работа каждого была бы сделана значительно лучше с глубоким пониманием рынка и продукта:
- Маркетинг не может написать пост про фичу, пока грамотный человек не проверит, что там не бред
- Нельзя написать на сайт, пока кто-то из R&D не подтвердит
- Очередь к экспертам -- у них своя работа

Экспертиза сконцентрирована в нескольких людях, и это ограничивает всех.

## Решение: агентная система как эксперт

Агентная система, которая является профессионалом в рынке и в нашем продукте.

Подключенные источники знаний (MCP -- как USB-коннекторы):
- **Векторный поиск** по документации нашего PAM (145 статей)
- **Векторный поиск** по документации CyberArk PAM (1700+ статей)
- **Playwright** -- доступ в интернет для ресерча
- **Kaiten** -- создание задач по результатам

## Кейс 1: экспертиза в рынке

Отправляем агентов исследовать тренды в Privileged Access Management.

Для демо -- веб-ресерч + готовый deep research по PAM-трендам 2025-2026.

Как повысить качество в реальности:
- Сложить в папку репорты Gartner по PAM за последние 3 года (нужна подписка)
- Обозначить конкретные сайты-источники для агентов
- Векторизировать репорты для семантического поиска

## Кейс 2: feature parity analysis

Сравниваем наш PAM с CyberArk PAM по документации.

Обе документации векторизированы -- агенты ищут по конкретным фичам в папках `our-pam/` и `competitors/cyberark/`.
