# Установка Kaiten MCP

Kaiten -- система управления задачами (как Jira или Trello). MCP-сервер даёт Claude Code работать с задачами напрямую: создавать карточки, двигать по колонкам, вести чеклисты, оставлять комментарии, логировать время. Всего 63 инструмента.

Ставим на Claude Code. Полная версия установки со всеми MCP курса -- в [demo/setup.md](../setup.md), разбор сценариев работы -- в [уроке 8](../lesson8/plan.md).

## Шаг 0. Проверить Node.js

MCP-сервер запускается через `npx`, который идёт вместе с Node.js. Проверьте в терминале:

```
node -v
```

Если команда не найдена -- поставьте Node.js LTS с https://nodejs.org (macOS и Windows -- обычный установщик с сайта) и откройте терминал заново.

## Шаг 1. Создать API-токен в Kaiten

1. Откройте ваш Kaiten (`https://your-company.kaiten.ru`).
2. Аватар в правом верхнем углу -> **Настройки профиля**.
3. В левом меню -- **API Key** -> **Создать токен**.
4. Скопируйте токен сразу: он показывается только один раз.

## Шаг 2. Узнать ID пространства и доски

ID видны прямо в адресной строке браузера:

- **Space ID** -- откройте пространство: `https://your-company.kaiten.ru/space/762572` -> `762572`.
- **Board ID** -- откройте доску: `https://your-company.kaiten.ru/space/762572/boards/1727446` -> `1727446`.

Запишите оба: агент будет спрашивать, на какой доске работать.

## Шаг 3. Подключить сервер

Способ первый -- одной командой в терминале, из папки курса:

```
claude mcp add kaiten -s project -e KAITEN_API_TOKEN=ваш-токен -e KAITEN_URL=https://your-company.kaiten.ru -- npx -y kaiten-mcp
```

Ключ `-s project` означает, что настройка запишется в файл `.mcp.json` в папке проекта.

Способ второй -- руками. Создайте в корне папки курса файл `.mcp.json` (или дополните существующий):

```json
{
  "mcpServers": {
    "kaiten": {
      "command": "npx",
      "args": ["-y", "kaiten-mcp"],
      "env": {
        "KAITEN_API_TOKEN": "ваш-токен-из-шага-1",
        "KAITEN_URL": "https://your-company.kaiten.ru"
      }
    }
  }
}
```

После любого из способов перезапустите Claude Code.

## Шаг 4. Подсказать агенту, как работать с Kaiten

Добавьте строку в `CLAUDE.md` в корне папки курса:

```
Read ./node_modules/kaiten-mcp/LLM_GUIDE.md before working with Kaiten.
```

Это гайд от самого MCP-сервера: иерархия объектов Kaiten, типовые сценарии, особенности API и частые ошибки. Агент прочитает его перед первой работой с задачами и не будет угадывать.

## Шаг 5. Проверка

Запустите Claude Code в папке курса и напишите:

> Покажи список пространств в Kaiten.

Если всё настроено, агент вызовет инструмент `kaiten_list_spaces` и покажет ваши пространства. Список подключённых серверов и их статус можно посмотреть командой `/mcp`.

## Если не заработало

- **Сервер не появился в `/mcp`** -- Claude Code читает `.mcp.json` при старте. Перезапустите его.
- **Ошибка авторизации** -- перепроверьте токен (он показывался один раз, при сомнении сделайте новый) и адрес в `KAITEN_URL`: он должен быть вида `https://your-company.kaiten.ru`, без слэша в конце и без пути.
- **`npx` не найден** -- вернитесь к шагу 0, Node.js не установлен или терминал открыт до установки.
- **Windows: сервер падает при старте** -- проверьте, что путь к папке курса не содержит кириллицы и пробелов в неожиданных местах, и запускайте Claude Code из этой же папки.
